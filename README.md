# Contest

A stick figure fighting game built in [Odin](https://odin-lang.org/).

## Requirements

- [Odin compiler](https://odin-lang.org/docs/install/) (installed via `brew install odin` on macOS)
- Odin's bundled `vendor:raylib` bindings (included with the compiler install)

## Setup

Clone the repo and make sure Odin is installed and on your `PATH`:

```sh
odin version
```

## Running the Game

```sh
./scripts/run.sh
```

This compiles the project and launches the window immediately.

To just build without running:

```sh
./scripts/build.sh
```

The compiled binary is placed at `build/contest`.
